TAREFA T11 — Testes de integração dos erros de formato (400) e do token (403)
Prioridade P0 · limite 04:15 · depende de: T05 (POST) e T07 (GET) mergeados

OBJETIVO
Cobrir com testes de integração caixa-preta (por HTTP, com o harness de tests/utils; NUNCA importe de src/) cada código de erro de formato do POST /pix/transaction e o 403 das duas rotas. Os testes checam `status` + `response["code"]`.
Códigos: RNV000001 (corpo que não é objeto JSON), RNV000007 (campo obrigatório ausente), RNV000008 (campo extra), RNV000009 (tipo/formato: CPF sem máscara, data sem fuso, data impossível, ISPB sem 8 dígitos), RNV000010 (valor fora do limite: amount < 1, latitude/longitude fora da faixa, tamanhos), RNV000002 (INTERNAL-TOKEN ausente ou errado, no POST e no GET).
Esta é uma tarefa só de teste: se um teste revelar que o schema (src/schemas/post_pix_transaction.json) ou o handler não se comportam como o catálogo (docs/catalogo-de-erros.md) diz, NÃO corrija: marque o teste com `pytest.mark.xfail(reason=...)`, descreva no PR e avise o Ramon.
